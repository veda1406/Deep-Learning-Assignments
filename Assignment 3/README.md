# Assignment 3: Forward Propagation, Backpropagation, Learning Rate, and Epochs

## Objective
Implement a neural network using TensorFlow/Keras and study how learning rates and the number of epochs affect classification performance.

## Dataset
**Scikit-learn Wine dataset**, with 13 input features and 3 target classes.

## Implementation
- Load the Wine dataset and split it into training and testing sets.
- Standardize the input features.
- Build an MLP with Dense layers and ReLU/Softmax activations.
- Compile and train the model using the Adam optimizer.
- Explain forward propagation, loss calculation, and backpropagation as handled during model training.
- Evaluate the model on the test set.
- Plot training/validation accuracy and loss.
- Train models with different learning rates and compare test accuracy.

## Technologies
- Python
- TensorFlow / Keras
- Scikit-learn
- NumPy
- Matplotlib

## Run
Open `DL_A3.ipynb` in Google Colab or Jupyter Notebook and run the cells from top to bottom. The Wine dataset is built into Scikit-learn.
