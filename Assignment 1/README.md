# Assignment 1: TensorFlow and Keras Basics

## Objective
Use TensorFlow/Keras to load a dataset, split it into training and testing sets, train a neural network, and evaluate its performance.

## Dataset
**Fashion-MNIST**, a built-in Keras dataset containing grayscale images of clothing items across 10 classes.

## Implementation
- Load the Fashion-MNIST training and testing sets.
- Inspect dataset shapes and labels.
- Normalize pixel values from the range 0–255 to 0–1.
- Visualize sample images and their class labels.
- Build a feed-forward neural network using `Flatten` and `Dense` layers.
- Train the model and evaluate its test performance.

## Technologies
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

## Run
Open `DL_A1.ipynb` in Google Colab or Jupyter Notebook and run the cells from top to bottom. No separate dataset download is required because Keras loads Fashion-MNIST automatically.
